カーソルの移動
h 左に移動
j 下に移動
k 上に移動
l 右に移動
Ctrl + e 画面を下に1行スクロール
（カーソル移動なし）
Ctrl + y 画面を上に 1 行スクロール
（カーソル移動なし）
Ctrl + b 画面全体分だけ上に移動
Ctrl + f 画面全体分だけ下に移動
Ctrl + d 画面半分だけ下に移動
Ctrl + u 画面半分だけ上に移動
H 画面上部に移動
M 画面中央に移動
L 画面下部に移動
gg 画面最上部に移動
G 画面最下部に移動
w 次の単語の先頭に移動
W 次の（区切り文字を含む）単語の先頭に移動
e 次の単語の末尾に移動
E 次の（区切り文字を含む）単語の末尾に移動
b 前の単語の先頭に移動
B 前の（区切り文字を含む）単語の先頭に移動
% 対応するカッコに移動（標準でサポートしている組み合わせは: '()','{}','[]' - 詳細は:h matchpairsを参照）
0 行頭に移動
^ その行で最初の非空白文字に移動
$ 行末に移動
g _ その行で最後の非空白文字に移動
g g ドキュメントの先頭行に移動
G ドキュメントの末尾行に移動
5 g g or 5 G 5行目に移動
g d move to local declaration
g D move to global declaration
f x 次にある文字「x」の手前に移動
t x 次にある文字「x」の 1 つ手前に移動
F x 前にある文字「x」の手前に移動
T x 前にある文字「x」の 1 つ後ろに移動
; 直前の f, t, F, T を繰り返し
, 直前の f, t, F, T を反対にして繰り返し
} 次の段落に移動（コード編集中の場合は関数/ブロック）
{ 前の段落に移動（コード編集中の場合は関数/ブロック）
z z カーソル位置を画面中央に

Tip これらのコマンドの前に番号を付けるとその回数分繰り返します。例えば、4j は 4 行下に移動します。

消去・複製・貼付
y y 行をヤンク
2 y y 2行をヤンク
y w 次の単語の始まりまでをヤンク
y $ 行末までヤンク
p カーソル位置の1つ後ろにペースト
P カーソル位置の手前にペースト
d d 行を消去
2 d d 2行を消去
d w 次の単語の始まりまでを消去
D 行末まで消去
d $ 行末まで消去（Dと同じ）
x 1文字消去
テキストインデント
> > その行を（右に）字下げ
< < その行を（左に）字上げ
> % () や {} のブロックを字下げ（カーソルが括弧にあるとき)
> i b () のブロックの内側を字下げ
> a t タグのブロックを字下げ
3 = = 3 行を再インデント
= % () や {} のブロックを再字下げ（カーソルが括弧にあるとき)
= i B {} のブロックの内側を再字下げ
g g = G バッファ全体を再字下げ
] p ペーストして現在の行にインデントを揃える
編集
r 文字を1つだけ置き換える
J スペースを1つ加えて下の行を現在の行に連結
g J スペースなしで現在の行に下の行を連結
g w i p 段落をすべて連結
g ~ モーション範囲の大文字小文字を切り替え
g u モーション範囲を小文字に
g U モーション範囲を大文字に
c c 現在の行を消去して挿入モード
C カーソル位置から行末までを消去して挿入モード
c $ カーソル位置から行末までを消去して挿入モード
c i w 単語を全て消去して挿入モード
c w 単語をカーソル位置から末尾まで消去して挿入モード
s カーソル位置の文字を消去して挿入モード
S 現在の行を消去して挿入モード（ccと同じ）
x p 二文字の入れ替え（カットしてペースト）
u 取り消し（アンドゥ）
U 最後に変更した行を取り消し（アンドゥ）
Ctrl + r やり直し（リドゥ）
. 最後に使ったコマンドを繰り返し
テキスト選択（ビジュアルモード）
v ビジュアルモード開始。これで選択してからコマンド（ヤンクなど）を実行
V 行単位のビジュアルモード
o 選択範囲の反対側に移動
Ctrl + v 矩形ビジュアル
O 矩形の反対側の角に移動
a w 単語を選択
a b () のブロックを選択
a B {} のブロックを選択
a t <> タグのブロックを選択
i b () ブロックの括弧を除いた内側を選択
i B {} ブロックの括弧を除いた内側を選択
i t <> タグのブロックの括弧を除いた内側を選択
Esc ビジュアルモード終了

Tip b や B の代わりにそれぞれ ( や { も使えます。

ビジュアルモードでのコマンド
> 選択範囲を右に
< 選択範囲を左に
y 選択範囲をヤンク
d 選択範囲を消去
~ 大文字と小文字を入れ替え
u 選択範囲を小文字に
U 選択範囲を大文字に
複数のファイルでの作業
:e[dit] file 新しいバッファでファイルを編集
:bn[ext] 次のバッファに移動
:bp[revious] 前のバッファに移動
:bd[elete] バッファを消去（ファイルを閉じる）
:b[uffer]# #番目のバッファに移動
:b[uffer] file fileという名前のバッファに移動
:ls or :buffers バッファのリストを開く
:sp[lit] file 新しいバッファの水平分割ウィンドウでファイルを開く
:vs[plit] file 新しいバッファの垂直分割ウィンドウでファイルを開く
:vert[ical] ba[ll] 全てのバッファを垂直分割ウインドウにして編集
:tab ba[ll] 全てのバッファをタブにして編集
Ctrl + w s ウィンドウ分割
Ctrl + w v ウィンドウ垂直分割
Ctrl + w w ウィンドウ切り替え
Ctrl + w q ウィンドウ終了
Ctrl + w x 現在のウインドウを次のウインドウと入れ替え
Ctrl + w = 全てのウインドウを同じ高さと幅に
Ctrl + w h 右のウィンドウ（垂直分割）にカーソル移動
Ctrl + w l 左のウィンドウ（垂直分割）にカーソル移動
Ctrl + w j 下のウィンドウ（水平分割）にカーソル移動
Ctrl + w k 上のウィンドウ（水平分割）にカーソル移動
